# Chanting Shlokas - GitHub Pages package

This folder is ready to publish with GitHub Pages.

Files:
- `index.html` - the webpage, with embedded audio replaced by relative links
- `audio/` - 44 extracted audio files
- `audio_manifest.csv` - mapping of audio file names to nearby labels from the original HTML

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `audio_manifest.csv`, and the entire `audio` folder.
3. In the repository, open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then Save.
6. GitHub will give you a URL such as `https://YOURNAME.github.io/REPOSITORY/`.

Important: GitHub Pages is public web hosting. Anyone who knows or discovers the URL can open the page. It is not password-protected.
